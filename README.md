# Pipeline Lakehouse para Análise de Acidentes de Trânsito do Município do Rio de Janeiro

## Descrição

Este projeto foi desenvolvido como MVP da disciplina de Engenharia de Dados do MBA da PUC-Rio.

O objetivo é construir um pipeline de dados ponta a ponta utilizando a arquitetura Lakehouse (Medallion Architecture) para ingestão, transformação, modelagem e análise de dados públicos sobre acidentes de trânsito no município do Rio de Janeiro.

## Objetivos

- Construir um pipeline de dados em ambiente de nuvem utilizando Databricks.
- Implementar a arquitetura Medalhão (Bronze, Silver e Gold).
- Modelar os dados para análises utilizando Star Schema.
- Aplicar boas práticas de Engenharia de Dados.
- Responder perguntas de negócio utilizando dados públicos do Data.Rio.

## Tecnologias

- Databricks Free Edition
- Apache Spark
- PySpark
- Spark SQL
- Delta Lake
- GitHub
- Python

## Fonte de Dados

- Data.Rio
- APIs e conjuntos de dados públicos da Prefeitura do Rio de Janeiro.
